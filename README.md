# Jam3yati — جمعياتي

تطبيق لإدارة الجمعيات المالية الدورية، مبني ليشمل الحسابات، الأعضاء، الدورات، الدفعات، الإيصالات، التقارير والتنبيهات.

## الحالة
- Android / Kotlin / Jetpack Compose
- Supabase جاهز لطبقة البيانات والمصادقة
- بنية أولية قابلة للتوسع إلى إصدار إنتاجي

## الوحدات
- تسجيل الدخول والحسابات
- إدارة الجمعيات والدورات
- إدارة الأعضاء والأدوار
- جدولة الدفعات والاستحقاقات
- الإيصالات والتقارير
- لوحة تحكم المدير
- الإشعارات

## الأمان
لا تضع مفتاح Supabase service_role داخل تطبيق Android. استخدم المفتاح العام/Publishable Key مع RLS.
